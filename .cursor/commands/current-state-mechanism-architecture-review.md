# Current-State Mechanism Architecture Review

Invoke the canonical workflow at:

- `/.octon/framework/orchestration/runtime/workflows/audit/current-state-mechanism-architecture-review/`

The workflow, not this command, is the execution contract. The review produces
retained evidence for a governed mechanism and does not authorize mutation or
redesign without a separate lifecycle route.
