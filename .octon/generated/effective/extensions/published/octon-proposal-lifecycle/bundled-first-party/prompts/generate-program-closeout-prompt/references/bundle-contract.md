# Bundle Contract

Program closeout prompts must refuse parent archival until child lifecycle
outcomes are implemented, archived, rejected, superseded, or covered by an
explicitly deferred report outcome.

They must also refuse closeout until parent aggregate conformance and
post-implementation drift receipts pass with child authority preserved.
Blocked closeout or archive readiness must be reflected in the generated
prompt's required parent-local receipt fields, including selected Git route,
hygiene blocker/count evidence, cleanup summary, and next route condition.
