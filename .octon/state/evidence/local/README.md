# Local Evidence

This root is for local-private evidence that should remain on the operator's
machine and should not be published by default.

Use this root for raw logs, cleanup authorizations, transcripts, local paths,
and other debug or audit material that is useful locally but not appropriate as
repo-publishable evidence.

Publishable evidence belongs under `.octon/state/evidence/runs/**` only after it
has been summarized or redacted into a concise receipt that is complete for the
claim it supports.
