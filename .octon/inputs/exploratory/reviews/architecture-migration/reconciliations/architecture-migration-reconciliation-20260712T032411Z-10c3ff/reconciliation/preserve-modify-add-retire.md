# Preserve, Modify, Add, Retire

## Preserve

- Typed authority/effect contracts, expiry/revocation fields, and useful exact-ref validators.
- Run Contract, context pack, support-target, route resolution, task-harness schema, Project Profile, adapter contracts, and provider guardrails.
- Evidence hash links/classifications, retention vocabulary, extension quarantine/publication, child scheduling/budget primitives, and promotion blocker readers.
- Manual/protected PR as the safe migration and escalation lane.

Preservation is not a completion claim. Each primitive remains subordinate to the reconciled source of truth and proof gates.

## Modify

- Install/pin authorization evaluator, policy floor, configuration, and executed receipt code outside candidate control; eliminate production weakening overrides.
- Replace string-prefix scope matching with typed identity/boundary-aware semantics.
- Route all agent/child launches through one guard-owning API.
- Move candidate execution to native macOS isolation, a fresh allowed environment, and an independent disposable repository.
- Migrate runtime authority to one SQLite/WAL operation state machine and demote legacy files to projections.
- Move Git/provider effects into one supervised credential broker with authenticated IPC.
- Convert current no-PR checks into expected-old fast-forward CAS with durable attempt/reconciliation state.
- Convert required status checks into authenticated candidate-immutable verifier verdicts.
- Extend evidence to signed observations/checkpoints, capacity, quotas, pins, compaction, and honest completeness.
- Extend promotion scaffolding to inert installation and previous-version activation/rollback.
- Extend existing route/harness primitives into the full per-run Harness Factory.

## Add

- Broker lifecycle: auto-start, single instance, enrollment, status, doctor, repair, upgrade, uninstall, restart/reconcile.
- Minimal Workspace Project schema, inference, correction, and lifecycle.
- Private extension signer/import/revocation/rollback contract.
- Child-agent guard/scope/depth/credential/retirement enforcement.
- Continuous provider-conformance and burden-budget receipts.

## Retire or remove from the supported path

- Lifecycle-local authority and raw agent spawn paths.
- Autonomous direct-main and ambient Git/provider credentials.
- Candidate-head verifier/effect workflows and ambiguous context-only check identity.
- Loose-file runtime authority and project-Git raw run exhaust.
- Same-change trust certification and unguarded activation.
- Public marketplace, enterprise IAM/compliance, distributed consensus, persistent autonomous organizations, VMs as target infrastructure, and unsupported federation/administration surfaces.

## Keep as-is decisions

- One serious solo operator remains the governing product boundary.
- macOS remains first-class, Linux experimental, native Windows/VM infrastructure out of scope.
- PR is an escalation/fallback lane, not the only publication endpoint.
- The local broker remains authoritative even if an optional provider worker performs an exact effect.
- Projects, harnesses, extensions, and provider adapters never authorize execution.
