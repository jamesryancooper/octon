# Exploratory Reviews

This surface retains non-authoritative review material used to inform governed
proposal revision and reconciliation. Review summaries and raw reviewer
evidence here never become runtime, policy, publication, generated,
state/control, or implementation authority.

Keep each review under `reviews/<review-family>/<review-id>/`. Raw reviewer
captures belong under that review's `evidence/` directory and remain historical
source material. Any durable conclusion must be adopted through the owning
proposal, Change, or retained-evidence route outside `inputs/**`.
