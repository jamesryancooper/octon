# Proposal Program Delivery Host Projections

This child packet publishes or corrects repo-local `.codex` projections for implemented proposal delivery wrappers.

The child is repo-local because active proposal validation separates `.octon` promotion targets from non-`.octon` promotion targets. Canonical runtime and product catalog changes remain owned by `.octon`-scoped child packets.

## Boundary

Host projections are discovery and operator convenience surfaces. They must mirror canonical `.octon` sources and must not authorize delivery, closeout, archive, cleanup, or terminal proof.
