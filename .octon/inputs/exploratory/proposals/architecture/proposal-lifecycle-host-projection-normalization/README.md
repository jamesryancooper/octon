# Lifecycle Host Projection Normalization

This child packet proposes a source-owned cleanup of proposal lifecycle command
and skill projection names across Codex, Claude, and Cursor.

The goal is to make lifecycle, delivery, closeout, and cleanup routes easier to
find and invoke without letting generated host projections or aliases become
authority. Durable implementation must update source manifests, projection
publisher behavior, validation, and docs before generated host files change.
