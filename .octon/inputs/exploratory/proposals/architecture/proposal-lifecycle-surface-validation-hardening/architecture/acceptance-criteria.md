# Acceptance Criteria

- Validators or tests detect required input drift across delivery surfaces.
- Validators or tests detect alias definitions that do not delegate to canonical delivery.
- Validators or tests distinguish intentional program review/revision asymmetry from missing lifecycle surfaces.
- Validators or tests detect product catalog claims that outstate host projection availability.
- Negative controls cover parent closeout, archive handoff, cleanup disposition, terminal proof, generated-output freshness, and child authority boundaries.
- Parent program evidence does not satisfy this child acceptance criteria.
