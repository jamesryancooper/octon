# Target Architecture

Lifecycle surface validation protects the accepted proposal lifecycle command, skill, workflow, contract, manifest, projection, catalog, and documentation set.

## Coherence Checks

- Packet and program lifecycle commands map to expected skills and workflows.
- Required delivery inputs agree across source surfaces.
- Alias commands delegate to canonical wrappers.
- Program review/revision is recognized as parent-local lifecycle behavior.
- Product catalog claims match available or intentionally narrowed host projections.

## Refusal Checks

- Parent closeout refuses non-terminal child outcomes without resolving evidence.
- Archive handoff refuses parent summaries as substitutes for child evidence.
- Cleanup checks refuse deletion without owning route authority.
- Terminal proof refuses generated, proposal-local, or host projection mirrors as authority.

## Evidence Checks

Validator output must distinguish behavior proof, boundary proof, generated-output freshness proof, and catalog/projection coherence proof.
