# Proposal Creation

This packet was created in response to a request to finalize an incoming
additive intake-unit contract from first principles using current Octon
architecture, governance, workflow, validator behavior, and input taxonomy.

Creation constraints:

- read-only with respect to actual `.incoming/**` and `.archive/**` intake
  units;
- no installation, normalization, activation, publication, archive movement,
  migration, or intake processing;
- no treatment of `.incoming/**` or `.archive/**` as runtime, policy,
  generated, retained evidence, state/control, publication, or host-projection
  authority.

The selected recommendation is a partial/minimal shape: required
non-authoritative metadata plus required free-form raw payload root.
