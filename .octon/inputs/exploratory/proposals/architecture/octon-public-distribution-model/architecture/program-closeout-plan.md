# Program Closeout Plan

## Preconditions

- Every required child has a terminal implemented, rejected, or superseded
  outcome through its own lifecycle.
- Implemented children retain fresh validation, conformance, drift, promotion,
  and closeout evidence.
- All six first-release blocker groups have final dispositions.
- Manual and external-effect actions are represented truthfully.
- No parent artifact claims publication unless an actual publication receipt
  exists outside proposal inputs.

## Aggregate Evidence

The parent may record child identifiers, exact evidence references, freshness,
verdicts, blocker status, and residual risks. It must not copy raw sensitive
evidence or repair missing child receipts.

## Archive Route

Run the canonical program closeout and archive route only after all preconditions
pass. If any child is active, blocked, stale, or ambiguous, keep the parent
active and report the exact owner and next gate.
