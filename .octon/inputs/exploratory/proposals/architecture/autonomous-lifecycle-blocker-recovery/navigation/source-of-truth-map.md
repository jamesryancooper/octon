# Source Of Truth Map

## Parent Coordination

- `proposal.yml`: parent manifest and lifecycle posture.
- `architecture-proposal.yml`: parent architecture framing.
- `resources/child-packet-index.yml`: structured child registry.
- `resources/child-packet-index.md`: human child index.
- `architecture/packet-sequence.md`: dependency and phase plan.
- `architecture/child-packet-contract.md`: child authority boundary.
- `architecture/program-closeout-plan.md`: later parent closeout conditions.

## Source Context

- `resources/source-postmortem-evaluation.md`: proposal-local postmortem input.
- `resources/source-traceability-matrix.md`: finding-to-child mapping.

## Child Truth

Each child packet owns its own proposal manifest, review, validation,
implementation, closeout, and archive receipts at its canonical sibling path.
Parent evidence may summarize child state but never replaces child-owned
receipts.
