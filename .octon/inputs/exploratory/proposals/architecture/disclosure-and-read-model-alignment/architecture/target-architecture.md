# Target Architecture

_Status: Accepted child target architecture_

## Target State

1. Run and release disclosure artifacts cite publishable evidence receipts and retained evidence refs, not raw local evidence.
2. Generated read models may summarize disclosure and evidence, but they remain rebuildable, freshness-bound, and non-authoritative.
3. Disclosure schemas distinguish operator-facing disclosure from publishable claim receipts and generated projections.
4. Raw local evidence can be mentioned only as a limitation or local reference, not as a hosted evidence dependency.

## Authority Boundary

This child may propose durable changes only under its promotion targets. It
must preserve the parent program's rule that local raw evidence, generated read
models, raw inputs, and proposal-local files do not satisfy evidence or closeout
gates.

## Non-Target State

The child does not target a clean-sheet evidence-store redesign, raw transcript
publication, generated-output authority, or parent-owned child receipt truth.
