# Target Architecture

The documentation set should use current terminology:

- `Governed Lifecycle Orchestration` for the current product feature;
- `governed cross-surface mechanisms` for architecture/governance docs;
- concrete runtime/operator terms for lifecycles, workflows, routes, state
  machines, receipts, commands, and skills.

`Lifecycle Autopilot` may remain only inside explicit compatibility notes or
historical lineage. Compatibility notes must not become current product,
runtime, policy, support, closeout, cleanup, generated, or retained-evidence
authority.
