# Target Architecture

_Status: Accepted child target architecture_

## Target State

1. Existing evidence under runs/skills is inventoried and classified as raw local evidence, publishable claim evidence, disclosure input, generated/read-model material, or manual-review residue.
2. Raw cleanup authorization and run logs are moved or copied only to local archive locations after digest and rollback posture are recorded.
3. Publishable replacements are created where hosted/shared closeout still needs claim evidence.
4. No evidence is deleted or discarded until local archive verification and child-owned safety evidence exist.
5. Parent program closeout cites child-owned terminal receipts and aggregate evidence only.

## Authority Boundary

This child may propose durable changes only under its promotion targets. It
must preserve the parent program's rule that local raw evidence, generated read
models, raw inputs, and proposal-local files do not satisfy evidence or closeout
gates.

## Non-Target State

The child does not target a clean-sheet evidence-store redesign, raw transcript
publication, generated-output authority, or parent-owned child receipt truth.
