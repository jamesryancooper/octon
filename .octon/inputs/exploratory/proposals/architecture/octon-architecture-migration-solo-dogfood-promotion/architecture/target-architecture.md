# Target Architecture

RP-14 is an independent reproducer, not another control plane. It receives
immutable child artifact and receipt references, an exact implementation
commit, provider observation timestamps, declared support tuples, and the
frozen acceptance matrix. It executes a repeatable proof protocol from a fresh
Solo Local installation across two projects, twenty representative missions,
failure/recovery fixtures, a thirty-day burden window, and exact provider
conformance reproduction.

The output is a signed or otherwise integrity-bound evidence set and claim map
that distinguishes demonstrated, limited, failed, disabled, and unclaimed
capabilities. It measures completion, delivery, unauthorized effects, prompts,
human time, mediation, recovery, false escalation, repository evidence growth,
setup/onboarding, administration, concepts, and provider drift. Raw operational
detail remains outside project Git.

Core claims may be evaluated only after RP-08, RP-09, RP-10, and RP-11. Signed
extension and bounded-child claims remain disabled until RP-12 and RP-13 pass;
full program closeout waits for both. Safe intermediate state SI-08 permits only
claim-scoped promotion of passing tuples. A failed or stale proof demotes the
claim, disables the affected route through its owning child, and preserves the
lower safe state. RP-14 never edits runtime, workflow, CLI, validator, provider,
support, or implementation surfaces to change the outcome.

The brokered publication cohort freezes `O`, `S`, `V`, and PR squash `Q`, route
and history policy, substantive harness/results, operation/attempt, landed
proof, mirror, cleanup, and preserved-work evidence. No-PR and PR cohorts use an
equal substantive validation floor. Candidate credential scans, malicious
candidate-head execution negatives, true expected-old CAS races, one-commit
default/bounded-series history, PR `S -> Q`, closed-unmerged preservation, and
provider-protection feasibility are mandatory. If true CAS needs bypass,
publication remains disabled and the product claim fails.
