# Solo Product Dogfood, Claim Reverification, and Promotion Handoff

RP-14 is the program's proof-only product gate. It consumes frozen child
outputs, runs fresh setup, two-project, 20-mission, 30-day, recovery, and
provider-drift proof, and produces a claim-to-evidence handoff. It may not fix
implementation to make proof pass. Any failed proof returns to the owning child.

Read `resources/packet-contract.yml`, the target and acceptance documents, the
validation plan, and `resources/traceability.yml` before the lifecycle receipts.
The sole durable target is RP-14's retained evidence root. Support admissions,
HarnessCard, roadmap, release, runtime, workflow, CLI, validator, and provider
surfaces remain downstream or child-owned.
