# Non-Goals

- Do not put Git, branch cleanup, repo hygiene, publication, archive, or Change
  closeout authority inside `proposal-program`.
- Do not teach `closeout-change` proposal child dependency ordering or proposal
  acceptance semantics.
- Do not use lifecycle postmortem as a closeout gate.
- Do not let generated implementation prompts authorize delivery effects.
- Do not let parent proposal-program summaries satisfy child-owned receipt
  requirements.
- Do not create a PR when the delivery profile declares a no-PR policy.
- Do not claim `cleaned` without terminal current-state proof, final sync proof,
  and final worktree hygiene.
- Do not treat generated outputs, raw inputs, proposal-local files, host state,
  dashboards, chat, model memory, or tool availability as authority.
