# Risk Register

| Risk | Mitigation |
| --- | --- |
| Aggregate evidence satisfies child receipts. | Validate child_authority_preserved and child receipt freshness separately. |
| Closeout collapses unrelated authority systems. | Require explicit separation of proposal lifecycle, Change closeout, worktree closeout, and repo hygiene. |
| Optional child blocks mandatory closeout accidentally. | Record deferred optional child resolution. |
