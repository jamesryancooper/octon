# Target Architecture

The program should have an aggregate closeout evidence surface that proves
mechanism coverage and boundary preservation without becoming child authority.

Required closeout coverage:

- mechanism coverage table for all required mechanisms;
- child terminal outcome table;
- child receipt freshness table;
- deferred optional child resolution;
- authority-boundary review;
- generated/input/read-model non-authority review;
- lifecycle interaction receipt non-authorization review;
- product feature catalog navigation-only review;
- retired terminology review;
- child_authority_preserved confirmation.
