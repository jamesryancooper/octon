# Operator Disclosure

The corrected runtime deliberately remains inconvenient for general GitHub
use. A live run requires a fresh exact pre-issuance authorization, immutable
operation plan, trusted nonsecret capture metadata, and one repository-selected
fine-grained PAT supplied through an inherited descriptor.

The operator must not paste the token into chat, arguments, environment, a
file, `gh`, browser automation, keychain, SSH, or Git remote. Capture metadata
must truthfully record facts observed during the sole issuance attempt; it is
not token bytes and does not prove facts GitHub does not expose.

If stage, provider outcome, PR identity, construction, or credential terminal
state is uncertain, the durable result is blocked. The system will not predict
an identifier, rewrite sealed authority, resend an unknown request, replace the
token, or use a UI action merely to finish the migration.
