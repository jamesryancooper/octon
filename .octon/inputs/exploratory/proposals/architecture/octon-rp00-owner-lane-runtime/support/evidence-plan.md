`.octon/state/evidence/validation/proposals/octon-rp00-owner-lane-runtime/<run-id>/`
and future provider evidence under the existing GitHub execution root.

Required classes:

- exact base/candidate commit/tree and promotion-target diff;
- schema syntax, registry, artifact-order, and independent canonicalization;
- preauthorization and operation-plan digest without post-event backreference;
- nonsecret capture metadata and generated issuance/lifecycle lineage;
- live-fact versus trusted-capture classification in admission evidence;
- exact PR create/reconcile/completed-prefix identity proof;
- typed suffix template normalization and construction receipts;
- authorized-effect issuance, verification, consumption, and replay denial;
- process-boundary proof of no secret in argv, environment, files, logs,
  evidence, or residual FIFO;
- ordered journal, outcome-unknown, no-resend, crash/resume, and conflict cases;
- terminalization, provider `401`, destruction, and empty census;
- lifecycle blocker scoping and non-conversion negatives;
- retained full staged hermetic run and current exact-operation support proof;
- inventory, authorization coverage, Rust, shell, conformance, drift, rollback,
  and diff-hygiene results.

Never retain token, Authorization header, revocation body, unredacted provider
payload, or a reversible secret-derived value.
