# Risk Register

| Risk | Scope | Posture | Mitigation |
| --- | --- | --- | --- |
| Autonomous recovery widens authority | lifecycle planner | high | Stop at material effects and retain recovery evidence. |
| Targeted freshness misses global drift | generated artifacts | medium-high | Keep full registry check as final gate. |
| Terminal summary becomes parent authority | child evidence | high | Summary refs child-owned evidence only and cannot replace receipts. |
| Proposal-program delivery postmortem overfits one historical run | lifecycle postmortem | medium-high | Define the profile for any completed proposal-program lifecycle and use fixtures that include delivery and non-delivery completed cases. |
| Postmortem recommendations become implicit implementation authority | lifecycle postmortem | high | Keep postmortem outputs evidence-only and require later proposal, review, and implementation authorization for durable changes. |
| Bounded branch-no-PR envelope over-authorizes effects | delivery | high | Stage proof locks before each effect and forbid PR fallback. |
| Completed-plan diagnostics hide active blockers | planner diagnostics | medium | Move only nonblocking post-terminal stale data to diagnostics. |
