# Target Architecture

The target architecture is a proposal-program lifecycle and delivery system that can autonomously recover from deterministic low-risk blockers while preserving explicit human authorization for material side effects.

## Target Capabilities

- Complete blocker vector output before mutation.
- Repository-supported validator runtime dispatch.
- Normalized proposal-program execution mode vocabulary.
- Normalized child terminal evidence summaries.
- Completed-plan nonblocking diagnostics.
- Targeted proposal freshness checks with full final registry gates.
- Batched review and strict architecture digest refresh.
- Bounded autonomous recovery envelopes.
- Retained delivery evidence indexes for local terminal proof bundles.
- Canonical branch-no-PR delivery receipt building.
- Branch-no-PR bounded authorization envelopes with staged proof locks.

## Authority Boundaries

Parent program evidence never satisfies child-owned receipts. Generated outputs remain derived-only. Local-only terminal evidence remains private/local unless referenced by a digest-bound retained index. PR fallback remains forbidden for branch-no-PR delivery.
