# Evidence Plan

## Proposal Evidence

- `support/proposal-creation.md` records creation route, source grounding,
  profile selection, and lifecycle boundary.
- `support/implementation-grade-completeness-review.md` records implementation
  readiness.
- `support/proposal-review.md` records accepted review and implementation
  prompt authorization after digest calculation.
- `support/executable-implementation-prompt.md` records the authorized
  implementation route.
- `support/implementation-run.md` records implementation execution.
- `support/implementation-conformance-review.md` records conformance.
- `support/post-implementation-drift-churn-review.md` records drift status.
- `support/proposal-closeout.md` records closeout and archive authorization.

## Implementation Evidence

- Interaction receipt validator output.
- Lifecycle contract validator output.
- Runner test output.
- Executor adapter test output.
- Extension publication receipt for generated projection refresh.
- Proposal registry or standard validator output.
- Change closeout receipt under retained closeout evidence.

All evidence must be fresh enough for the gate claiming it and must cite
durable refs rather than chat memory.
