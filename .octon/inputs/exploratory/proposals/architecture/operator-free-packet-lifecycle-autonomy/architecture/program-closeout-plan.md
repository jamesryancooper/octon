# Program Closeout Plan

The parent program may close only after all required child packets reach a
terminal disposition with child-owned evidence.

## Closeout Gates

- All P0 children are implemented, rejected, or explicitly superseded.
- P1 children are implemented or intentionally deferred with review evidence.
- Child-owned receipts remain the source of child status.
- Aggregate program evidence summarizes child outcomes without replacing them.
- Generated-output non-authority validation passes for any child that touches
  generated freshness surfaces.
- Worktree hygiene reports no foreign or ambiguous residue, or every remaining
  item has accepted retained/foreign disposition.
- No active proposal-path backrefs remain in durable targets.

## Archive Readiness

Archive is allowed only after parent review, program implementation
orchestration evidence, program conformance evidence, drift/churn evidence, and
closeout evidence are fresh and pass with no unresolved blockers.
