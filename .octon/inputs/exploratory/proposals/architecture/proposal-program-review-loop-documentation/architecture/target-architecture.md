# Target Architecture

Program review/revision is discoverable as an intentional parent-local lifecycle loop.

## Program Review

- Reviews the parent manifest, child registry, human index, packet sequence, child packet contract, validation plan, closeout plan, and parent support artifacts.
- May write parent-local review receipts.
- May update only parent manifest status through authorized review routes.

## Program Revision

- May change only parent-local coordination files.
- May write parent-local revision receipts.
- Must not mutate child manifests, child receipts, child validation verdicts, child archive metadata, or child terminal outcomes.

## Wrapper Decision

No standalone program review-and-revise wrapper is added unless future evidence shows the generic program lifecycle runner cannot execute the existing review/revision loop clearly.
