# Migration State and Recovery Register

| State | Required boundary | Prohibited bridge | Recovery |
| --- | --- | --- | --- |
| SI-00 Contained baseline | unsafe writers/direct-main disabled; truthful inventories/claims | privileged autonomous implementation | retain unsafe-route disablement |
| SI-01 Trusted authority | immutable evaluator and exact guards | brokered effects | prior certified authority or disable launch |
| SI-02 Isolated candidate | useful credentialless independent repo/session | canonical Git/credentials/privileged IPC | preserve exported candidate; disable launch |
| SI-03 Transactional truth | one SQLite/WAL writer; read-only projections | dual writers/file authority after effect | certified crash-consistent state, reconcile/repair forward |
| SI-04 Local broker | authenticated IPC, Keychain custody, one scratch effect | production Class B or route switching | disable broker; preserve work; PR only if a fresh pre-effect policy decision independently selects it |
| SI-05 Git/verifier | sanitized Git and separate exact-SHA verifier | production landing before evidence/recovery | certified adapter/verifier or disable route |
| SI-06 Recoverable Class B | signed capacity-safe evidence, frozen route, exact tuple, and UNKNOWN reconciliation | blind retry, route switching, trust automation/broad claims | reconcile UNKNOWN; invalidate raced tuple; preserve work; require fresh authority for any new attempt |
| SI-07 Safe self-development | inert trust changes; prior-version activation/rollback | same-change self-certification | exact certified old version or remain inert |
| SI-08 Complete solo target | projects/Harness and claim-scoped dogfood/proof | reconciliation/proposal as authority | demote failed claims; preserve lower safe states |

Advancing requires child-owned exit proof. Rollback never restores a bridge
listed as prohibited.

Canonical local `main` is a downstream mirror only. Mirror or cleanup failure
does not undo landed proof, delete candidate work, or permit a false `cleaned`
terminal state.
