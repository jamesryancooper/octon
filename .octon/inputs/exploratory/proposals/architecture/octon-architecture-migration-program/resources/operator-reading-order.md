# Operator Reading Order

## Milestone 1 — Containment

Read RP-00 with accepted ROD-006: Octon owns no human or agent direct-main
route. Confirm unsafe writers/routes stay disabled and inventories/claims are
truthful.

## Milestone 2 — Safe Candidate Foundation

Read RP-01–RP-04, then RP-10/RP-11. Focus on one issuer, isolation, one writer,
one broker, project non-authority, Harness binding, and the RP-01→RP-03 freeze.

## Milestone 3 — Verified Delivery

Read RP-05/RP-06. Confirm sanitized Git, separate exact-SHA verifier, deterministic
Class B/PR predicate, and `.octon` ownership of host projections.

## Milestone 4 — Recovery and Trust

Read RP-07–RP-09. Confirm signed capacity-safe evidence, UNKNOWN reconciliation,
no universal exactly-once claim, inert trust changes, and prior-version rollback.

## Milestone 5 — Optional Capabilities and Product Proof

Read RP-12/RP-13, then proof-only RP-14. Confirm optional claims remain disabled
until their own proof and that the final operator view meets the setup,
completion, safety, speed, recovery, concept, and administration budgets.

At every milestone, use the child receipt rather than parent summary and retain
the lower safe state when a gate fails.
