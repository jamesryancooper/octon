# Target Architecture

The test matrix covers:

- Parent review accepted path.
- Parent review revision-required loop.
- Child review accepted path.
- Child review revision-required loop.
- Missing or stale strict pre-integration architecture review.
- Program implementation orchestration prompt and run evidence.
- Child closeout, terminal closeout, and archive handoff.
- Proposal-program delivery admission.
- Change closeout and closeout-worktree handoff.
- Final sync, cleanup proof, and terminal current-state proof.
- Blocked and resume paths.
- Non-authority negative controls.
