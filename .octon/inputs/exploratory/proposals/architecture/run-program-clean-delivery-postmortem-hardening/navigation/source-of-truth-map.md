# Source Of Truth Map

| Surface | Authority Role |
| --- | --- |
| `proposal.yml` | Parent program manifest and coordination scope |
| `resources/child-packet-index.yml` | Machine-readable child registry |
| `resources/child-packet-index.md` | Human-readable child index |
| `architecture/packet-sequence.md` | Sequencing rationale |
| `architecture/child-packet-contract.md` | Child authority boundary |
| Child packet directories | Child-owned proposal authority and future implementation evidence |
| Proposal Program Delivery receipts | Future aggregate delivery evidence |
| Change closeout receipts | Future Git landing, sync, cleanup, and terminal evidence |
| Repo-hygiene cleanup receipts | Future deletion authorization |

The parent program never replaces child-owned receipts, delivery receipts,
Change receipts, cleanup authorization, or terminal proof.
