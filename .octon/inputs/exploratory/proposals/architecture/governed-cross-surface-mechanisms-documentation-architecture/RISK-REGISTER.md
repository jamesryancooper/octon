# Risk Register

| Risk | Impact | Mitigation |
| --- | --- | --- |
| Product feature entries become authority-like. | Product navigation could be mistaken for runtime or policy truth. | Keep product catalog `catalog_role: navigation-only`; add validator checks and product docs cross-links only. |
| `state/control/**` is mislabeled retained evidence. | Live control truth and proof records blur. | Align authority classes with the topology registry and reject bad path/class pairs. |
| Generated-effective files are treated as source authority. | Runtime resolution bypasses handle/freshness gates. | Require generated-effective non-authority labeling and resolver-verified handle references. |
| Operator read models are treated as runtime truth. | Visibility projections could drive policy or support decisions. | Require generated operator read-model class and forbidden-consumer metadata. |
| Lifecycle interaction receipts are treated as authorization. | Advisory handoff context could authorize target work. | Add boundary notes and negative validator controls. |
| Parent program evidence satisfies child receipts. | Child-owned proposal lifecycle truth is weakened. | Enforce parent coordinates only and child receipt freshness rules. |
| Proposal lifecycle, Change closeout, worktree closeout, and repo hygiene collapse. | Authority systems merge incorrectly. | Add explicit boundary guide and closeout/repo hygiene notes. |
| Retired terminology returns. | Design ambiguity around Governed Lifecycle Orchestration. | Contain `Lifecycle Autopilot` to compatibility or historical notes and validate usage. |
