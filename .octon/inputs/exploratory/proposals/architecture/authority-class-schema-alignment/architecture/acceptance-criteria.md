# Acceptance Criteria

This child packet is implementation-ready when:

1. The vocabulary is aligned to the topology registry.
2. Product feature catalog entries remain navigation-only.
3. Product contracts remain product contract surfaces.
4. Runtime specs and runtime implementations remain distinct classes.
5. `state/control/**` is mutable operational truth.
6. `state/evidence/**` is retained evidence.
7. Generated-effective surfaces remain non-authority runtime handles.
8. Generated operator read model surfaces remain visibility-only.
9. Raw/input and publication-input-only surfaces cannot become runtime or
   policy authority through schema wording.
10. Compatibility-only surfaces cannot become steady-state runtime authority.
