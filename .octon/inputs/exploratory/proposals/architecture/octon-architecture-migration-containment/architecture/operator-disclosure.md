# Operator Disclosure

## What Changes After Future RP-00 Implementation

- Agents no longer work or publish directly on `main`.
- Candidate-controlled workflows cannot perform privileged provider writes.
- Until later packets pass, autonomous publication is blocked. Protected PR is
  shown only for independently review-selected work after its boundary is proved.
- Octon reports only support and proof it can directly substantiate.
- Physical trust-sensitive surfaces are inspectable through one coverage map.

## Normal Solo-Builder Experience

The operator continues ordinary candidate work without a new control plane or
new routine approval ceremony. If work needs a privileged landing before the
later publication spine is proven, Octon preserves the candidate commit and
reports the route as blocked unless an independent review predicate already
selected a proved-safe protected PR. Status output should state one reason, one safe
route, and the evidence reference; raw inventories remain available for
diagnosis rather than normal display.

## Settled Operator Posture

ROD-006 is accepted: Octon exposes no human or agent direct-main route.
Ordinary human Git remains outside Octon and is not an Octon support surface.
Protected PR is a deterministic review-selected route, not a universal bridge
or failure fallback. No further operator decision is
required here.

## What This Packet Does Not Provide

RP-00 does not provide credentialless candidate isolation, a transactional
store, a broker, sanitized Git, immutable verification, autonomous Class B
publication, signed evidence, unknown-outcome recovery, trust activation,
Workspace Projects, Harness Factory, extensions, child agents, or final solo
product proof. Describing SI-00 as completion would be a claim violation.

## Failure Experience

When containment evidence is missing or stale, Octon stops privileged work,
preserves candidate output, and explains any independently selected PR path. It
does not fall back to ambient credentials, candidate-head workflows, direct
main, or a broader claim.
