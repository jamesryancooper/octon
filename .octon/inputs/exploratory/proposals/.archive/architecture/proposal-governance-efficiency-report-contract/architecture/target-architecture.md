# Target Architecture

The report contract should define a structured advisory artifact with fields for:

- evaluated surface or feature;
- governance controls observed;
- risk covered;
- evidence produced;
- latency and retry cost;
- failure and blocker signals;
- automation candidate status;
- batching candidate status;
- risk-based candidate status;
- redundancy findings;
- uncertainty and missing evidence;
- recommendation and recommended next owner.

Every report must state that it is advisory and cannot authorize lifecycle transitions.
