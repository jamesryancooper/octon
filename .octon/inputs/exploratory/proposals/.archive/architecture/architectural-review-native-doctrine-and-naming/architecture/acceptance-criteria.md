# Acceptance Criteria

- Native methodology includes the Balanced Architecture Review Method.
- The Architectural Review Mechanism display name and family slug are defined.
- Canonical display names, slugs, workflow directories, schemas, validators,
  evidence roots, and support artifact names are documented.
- `architecture-readiness-audit` is canonical.
- `architecture-readiness-audit` retirement has a bounded migration window,
  retirement condition, and validator target.
- Extension prompt context no longer owns the method after later cleanup.
- No generated or proposal-local artifact becomes naming authority.
