# Target Architecture

## Validator Matrix

Final rollout includes validators for:

- naming;
- routing;
- report schema;
- routing decision schema;
- support receipt schema;
- workflow contracts;
- skill and command invocation boundaries;
- proposal pre-integration gate;
- post-integration closeout boundaries;
- governed mechanism index;
- extension/native split;
- generated projection freshness.

## Negative Controls

Negative controls reject missing evidence, stale digests, omitted validators,
placeholder receipts, generated-output authority, extension gate substitution,
post-integration review closeout substitution, and permanent legacy aliases.

## Publication

Generated registries, artifact indices, child handoff capsules, skill
projections, and host projections are refreshed by scripts only.
