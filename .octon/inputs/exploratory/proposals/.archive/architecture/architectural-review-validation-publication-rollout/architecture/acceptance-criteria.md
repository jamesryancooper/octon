# Acceptance Criteria

- Full validator matrix exists and runs.
- Positive and negative fixtures cover every architectural review mode and gate.
- Generated proposal registry and compact artifacts are fresh.
- Skill and host projections are refreshed by publication scripts when affected.
- Rollout evidence records phase completion and blockers.
- Completion gates require child-owned implementation, conformance, drift/churn,
  promotion, and closeout evidence.
