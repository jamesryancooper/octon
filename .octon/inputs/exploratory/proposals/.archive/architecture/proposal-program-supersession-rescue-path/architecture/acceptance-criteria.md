# Acceptance Criteria

- Polluted runs freeze before further mutation.
- Freeze evidence is explicitly non-authorizing.
- Validated child-owned receipts are carried forward by ref and digest.
- Missing or stale child-owned receipts remain blockers.
- Deliverable changes are partitioned from foreign/manual residue.
- Successor-run creation binds baseline, ownership classification, carried evidence, and rollback posture.
- Normal Change closeout remains the owning route for deliverable publication or landing.
