## Boundary Rules

- Parent and aggregate evidence may cite child-owned evidence by path and
  digest only.
- Proposal-local docs and support receipts may guide implementation but cannot
  replace durable authorities or retained evidence.
- Raw additive inputs must be published and freshness-validated before runtime
  consumers rely on generated effective route state.
- Generated outputs must be regenerated by owning publisher scripts and
  validated for freshness; direct hand edits are invalid.
