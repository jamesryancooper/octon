- Required and optional delivery inputs agree across canonical workflow, command, skill, contract, manifest, validator, and lifecycle documentation surfaces.
- Missing required delivery inputs fail before mutation.
- Valid resume paths specify the retained receipt or run evidence that satisfies the input.
- Packet-level and program-level delivery differences are documented and tested without forcing false symmetry.
- Host projection publication remains blocked until this child closes or is explicitly superseded.
- Parent program evidence does not satisfy this child acceptance criteria.
