# Acceptance Criteria

- `artifact-ownership-unclear`, `worktree-hygiene-blocked`, stale-fingerprint,
  and equivalent closeout ambiguity route to a target-owned recovery path.
- Recovery receipts bind current fingerprint, residue classes, dispositions,
  authority boundaries, and rerun-gate command/result.
- If cleanup-safe count is `0` and a non-mutating preserve/exclude route binds
  the current fingerprint, the lifecycle continues automatically after the
  rerun gate passes.
- Lifecycle continuation happens automatically only after the rerun gate passes.
- Negative controls stop on destructive cleanup without authority, protected
  refs, external credentials, stale recovery evidence, and unpreservable
  foreign or ambiguous residue.
