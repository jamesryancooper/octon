# Target Architecture

After the mandatory mechanism index is stable, Octon may add optional
per-mechanism detail pages and generated operator maps.

Target posture:

- detail pages remain architecture/governance documentation;
- generated operator maps are operator read models;
- operator read models are navigation only, visibility only, and
  non-authority;
- generated maps include source traceability and freshness metadata;
- generated maps are forbidden as runtime, policy, support, authority, or
  closure input.
