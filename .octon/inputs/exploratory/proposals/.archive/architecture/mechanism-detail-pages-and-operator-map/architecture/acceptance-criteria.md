# Acceptance Criteria

This formerly optional child packet is implementation-ready for this selected
program run when:

1. It records explicit selected-run scope in child-owned packet metadata.
2. It participates in selected-run closeout only through child-owned receipts;
   parent aggregate evidence cannot satisfy this child.
3. Operator read models are navigation only.
4. Operator read models are visibility only.
5. Operator read models are non-authority.
6. Generated maps include source traceability and freshness metadata.
7. Generated maps cannot be runtime, policy, support, authority, or closure
   input.
