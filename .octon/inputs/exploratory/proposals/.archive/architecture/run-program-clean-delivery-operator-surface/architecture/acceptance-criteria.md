# Acceptance Criteria

- Operators can invoke clean delivery with `/proposal-program-delivery`.
- The entrypoint reports blockers and next owning routes without asking for
  routine steps.
- The entrypoint does not authorize implementation, delivery, Git mutation,
  cleanup, archive, branch cleanup, terminal proof, or a final `cleaned` claim.
- Feature catalog coverage includes runtime surfaces, evidence refs,
  validators, related docs, and authority/non-authority notes.
- The lifecycle-runner command and skill document `target_outcome=cleaned` as a
  Proposal Program Delivery handoff request, not completion proof.
- Documentation states that branch-no-pr is valid only when policy allows and
  no PR predicate exists.
