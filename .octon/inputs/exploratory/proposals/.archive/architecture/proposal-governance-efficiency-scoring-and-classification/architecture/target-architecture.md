# Target Architecture

Scoring should classify governance controls across these dimensions:

- risk coverage;
- evidence uniqueness;
- latency cost;
- retry and failure rate;
- determinism and automation fit;
- batching and caching fit;
- risk-based treatment fit;
- redundancy;
- uncertainty.

The result is a recommendation with a confidence level and a next owning lifecycle or proposal route. The recommendation does not authorize any governance change by itself.
