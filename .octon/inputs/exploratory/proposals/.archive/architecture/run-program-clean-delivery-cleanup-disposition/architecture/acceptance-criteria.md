# Acceptance Criteria

- Worktree residue is classified before cleanup or preservation.
- Closeout-worktree returns bind to the classifier fingerprint and describe authorized cleanup or preservation.
- Detection alone never authorizes deletion.
- Cleanup loops stop when the same preflight blocker recurs and surface exact blocker evidence.
- Positive and negative fixtures cover generated, protected, foreign, disposable, and preserve-only residue.
