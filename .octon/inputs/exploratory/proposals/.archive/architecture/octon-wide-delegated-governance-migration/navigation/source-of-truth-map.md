# Source Of Truth Map

- `proposal.yml` is the parent program manifest.
- `resources/child-packet-index.yml` is the structured child registry.
- `resources/child-packet-index.md` is navigation only.
- `architecture/packet-sequence.md` defines child execution order.
- `architecture/child-packet-contract.md` defines parent and child authority boundaries.
- `architecture/program-closeout-plan.md` defines parent closeout gates.
- `support/program-creation.md` records parent creation evidence.
- `support/proposal-review.md` records parent review evidence.
- `support/program-implementation-orchestration-run.md` records parent aggregate
  implementation orchestration results without satisfying child receipts.
- `support/program-implementation-orchestration-conformance-review.md` records
  parent aggregate conformance verification without replacing child authority.
- `support/program-post-implementation-orchestration-drift-churn-review.md`
  records parent aggregate drift/churn verification without replacing child
  authority.
- `support/lifecycle-residue-cleanup.md` records parent lifecycle residue
  cleanup evidence for closeout readiness.
- `support/custom-program-closeout-prompt.md` records the parent closeout prompt
  generated by the lifecycle route; it is an operational aid, not authority.
- `support/proposal-closeout.md` records parent closeout and archive
  authorization without satisfying child receipts or child authority.

The accepted architecture packet is source context. Durable authority remains in
promoted repository contracts, runtime code, control files, retained evidence,
and validated promotion receipts, not in this parent program.
