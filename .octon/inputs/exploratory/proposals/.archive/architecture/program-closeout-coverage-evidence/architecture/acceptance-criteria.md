# Acceptance Criteria

This child packet is implementation-ready when:

1. Aggregate closeout evidence is scoped as summary evidence, not child
   authority.
2. Mechanism coverage includes every required mechanism from the architecture
   evaluation.
3. Child receipt freshness remains child-owned.
4. child_authority_preserved is explicit.
5. Parent evidence cannot satisfy child packet receipts.
6. Optional deferred child handling is explicit.
7. Proposal lifecycle, Change closeout, worktree closeout, and repo hygiene are
   not collapsed into one authority system.
8. Generated, raw, host, navigation, and receipt surfaces remain non-authority
   where required.
