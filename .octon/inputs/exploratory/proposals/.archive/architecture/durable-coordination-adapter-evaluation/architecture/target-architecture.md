# Target Architecture

Durable coordination adapters are implemented as lab-evaluated, replaceable
coordination support candidates.

The target state adds:

- a lab evaluation record for durable coordination adapter behavior;
- a non-live connector admission boundary record for stage-only evaluation;
- retained lab proof with positive scenario evidence and negative controls;
- a shared adapter evaluation boundary contract;
- a validator proving durable adapter state cannot become control, evidence,
  authority, support, or closeout truth.
