# Target Architecture

## Closeout Gates

Hard closeout gates remain:

- implementation conformance review;
- post-implementation drift/churn review.

## Evidence-Only Reviews

Evidence-only unless later policy changes the contract:

- Post-Integration Architecture Review;
- Current-State Mechanism Architecture Review when run outside a proposal gate;
- Lifecycle Postmortem Evaluator output.

## Prohibited Authority Claims

Lifecycle postmortems cannot authorize closeout, promotion, redesign, support
widening, generated publication, or constitutional amendment.
