# Acceptance Criteria

- Documentation and validators preserve conformance and drift/churn as hard
  closeout gates.
- Post-Integration Architecture Review is optional evidence-only in the initial
  rollout.
- Lifecycle postmortem authority limits are explicit.
- Validators reject closeout based only on post-integration review or
  postmortem evidence.
- Future policy can select post-integration review as a gate only through a
  separate accepted policy or architecture change.
