# Acceptance Criteria

- Missing catalog entries are flagged for new implemented product-facing or
  cross-surface features.
- Stale catalog entries are flagged for removed or retired features.
- Under-documented changed features are flagged when refs, evidence,
  validators, related docs, or authority notes no longer match reality.
- Status mismatches are flagged.
- Rename, split, merge, and downgrade cases are represented.
- Non-product-feature helpers, generated-only projections, raw inputs, and
  capability-library-only surfaces are excluded with explicit rationale.
