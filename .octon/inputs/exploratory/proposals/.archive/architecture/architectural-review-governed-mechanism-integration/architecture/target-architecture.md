# Target Architecture

## Mechanism Entry Fields

The Architectural Review Mechanism entry records:

- authority refs;
- product refs if any;
- workflow refs;
- mutable control refs;
- retained evidence refs;
- generated refs;
- raw input refs;
- validators;
- ownership boundaries;
- non-authority boundaries.

## Non-Authority Boundaries

The entry must state that raw inputs, proposal packets, generated projections,
review reports, extension packetization helpers, skills, host state, chat,
dashboards, and model memory are not authority.
