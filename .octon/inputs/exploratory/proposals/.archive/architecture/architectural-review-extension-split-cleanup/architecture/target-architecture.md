# Target Architecture

## Extension-Owned

- source and concept intake;
- concept extraction and verification;
- multi-source synthesis;
- source-to-packet generation;
- Architecture Revision Packet packetization helper;
- convenience prompt bundles;
- extension prompt alignment and publication.

## Native-Owned

- architectural review doctrine;
- Balanced Architecture Review Method;
- schemas, validators, workflows, evidence contracts, and lifecycle gates;
- canonical naming model.

## Compatibility Cleanup

Extension prompts reference native doctrine and remove duplicate ownership
claims. Compatibility paths are bounded and retired by validator-backed checks.
