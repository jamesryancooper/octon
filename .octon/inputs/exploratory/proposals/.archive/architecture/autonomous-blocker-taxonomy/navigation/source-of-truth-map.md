# Source Of Truth Map

- `proposal.yml`: child manifest and scope.
- `architecture-proposal.yml`: architecture framing.
- `architecture/target-architecture.md`: proposed taxonomy target.
- `architecture/implementation-plan.md`: future implementation sequence.
- `architecture/acceptance-criteria.md`: packet acceptance criteria.
- `resources/source-context.md`: parent postmortem context.
- `support/implementation-run.md`: implementation receipt and durable
  promotion summary.
- `support/implementation-conformance-review.md`: implementation conformance
  evidence.
- `support/post-implementation-drift-churn-review.md`: post-implementation
  drift and churn evidence.
- `support/proposal-closeout.md`: child-owned closeout receipt, archive
  authorization, hygiene evidence, and durable promotion evidence refs.
- `support/validation.md`: validation receipt for the implementation route.

Parent program evidence may summarize this child, but it cannot satisfy this
child packet's future review, implementation, validation, closeout, or archive
receipts.
