## Retained Evidence Expectations

- Disclosure-tier validator logs with hosted/shared positive controls and
  local/private negative controls.
- Terminal local evidence manifests with source refs, local evidence root,
  terminal transcript or digest refs, and explicit retained-evidence-only
  classification.
- Generated metadata refresh receipts with source/output digests and
  non-authority classification.
- Proposal registry and artifact-index validation logs retained under the
  owning validation evidence root.

## Rollback And Closeout Expectations

- Rollback reverts the receipt schema, terminal writer, disclosure validator,
  proposal registry generator, and proposal artifact-index generator together.
- Generated metadata refreshes are regenerated by owning generators after
  rollback; generated files are not hand edited.
- Closeout remains blocked if hosted/shared receipts cite local/private landing
  or cleanup refs, generated metadata lacks source/output digests, or validators
  cannot identify the next owning route for misplaced evidence.

## Out Of Scope

- Runner dispatch, workflow sequencing, archive, branch cleanup, Git mutation,
  durable implementation in this route, generated publication in this route,
  terminal proof synthesis, and any `cleaned` claim.
