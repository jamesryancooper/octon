## Implemented Changes

- The Change receipt schema now requires digest-backed local terminal
  current-state proof refs and publishable evidence receipt refs for completed
  hosted/shared cleaned branch outcomes.
- The local terminal closeout writer validates snapshot receipt boundaries
  before writing retained local evidence and invokes the disclosure-tier
  validator against the copied Change receipt.
- The disclosure-tier validator now rejects local/private, generated, and input
  refs in hosted/shared authorization and evidence fields, validates
  digest-backed local terminal proof refs, validates sibling local terminal
  manifests, and requires explicit stop reasons for blocked cleaned targets.
- The proposal registry generator now emits deterministic refresh receipts with
  source refs, source digests, output digest posture, derived-only
  classification, refresh status, and next owning route.
- The proposal registry generator now tolerates only historical superseded
  archive evidence drift when the sole base-validator error is a missing
  historical supersession evidence path, preserving projection freshness while
  keeping the base proposal validator strict.
- The proposal artifact-index generator now emits matching refresh receipts for
  artifact index, program spine, and handoff capsule outputs.
