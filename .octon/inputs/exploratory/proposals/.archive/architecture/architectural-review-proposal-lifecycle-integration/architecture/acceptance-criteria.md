# Acceptance Criteria

- Proposal standards document the mandatory pre-integration review gate.
- Create, audit, validate, promote, and archive proposal workflows reference the
  gate where appropriate.
- Validators reject missing, stale, schema-invalid, non-passing, and incomplete
  receipts.
- Negative controls prove chat, generated output, proposal-local prose, or
  extension packets cannot satisfy the gate.
- Existing implementation conformance and drift/churn closeout gates still run.
