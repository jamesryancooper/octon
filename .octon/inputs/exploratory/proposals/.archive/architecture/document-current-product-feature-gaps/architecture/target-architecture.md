# Target Architecture

The product feature catalog contains machine-readable entries for all 24
audited feature gaps. Each entry has accurate implementation status,
entrypoints, authoritative refs, runtime surfaces, extension surfaces where
relevant, generated/evidence refs, validation refs, related docs, and authority
notes.

Feature notes exist where a human boundary explanation is needed, especially
for non-authority generated outputs, evidence-only receipts, and stage-only or
under-documented surfaces.
