# Acceptance Criteria

- All 24 audited feature ids are represented in `catalog.yml` with accurate
  status and complete reference sections.
- Existing partially documented surfaces are either expanded or explicitly
  folded into a documented parent feature.
- Feature notes exist where boundary explanation is necessary.
- Generated outputs, raw inputs, host projections, and evidence paths are
  classified with non-authority/evidence-only notes.
- `validate-product-feature-catalog.sh` passes.
