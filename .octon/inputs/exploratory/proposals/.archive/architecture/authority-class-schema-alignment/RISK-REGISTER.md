# Risk Register

| Risk | Mitigation |
| --- | --- |
| Product feature entries become authority-like. | Keep catalog role navigation-only and validate the schema language. |
| `state/control/**` is mislabeled retained evidence. | Add negative controls and require mutable operational truth wording. |
| Generated operator read model is confused with generated-effective runtime handle. | Keep both classes explicit in docs and validators. |
| Raw inputs become policy or runtime dependencies. | Preserve exploratory/raw input and publication-input-only classes. |
