# Custom Program Closeout Prompt

Close out `governed-workflow-runtime-transition-program` only if:

- all required children are archived implemented with child-owned retained
  promotion evidence;
- deferred evaluation candidates have explicit non-required disposition evidence;
- parent aggregate evidence summarizes child outcomes without replacing child
  receipts;
- no generated projection, external system state, MCP descriptor, tool
  availability, Durable Object state, dashboard, agent output, or proposal-local
  artifact is treated as Octon authority;
- final proposal registry generation/check, parent checksum, worktree hygiene,
  git status, and stash checks pass.

Refuse closeout if any active implemented/archive-authorized child remains
unarchived or if an archived parent child index contains stale active child
packet paths.
