# Acceptance Criteria

This child packet is implementation-ready when:

1. Product docs consistently use product features.
2. Architecture/governance docs consistently use governed cross-surface
   mechanisms.
3. Product feature catalog entries remain navigation-only.
4. Crosslinks clarify where authority-class detail lives.
5. Crosslinks do not make runtime/operator mechanisms product features by
   implication.
6. Crosslinks do not make product docs runtime, policy, closeout, cleanup,
   generated, evidence, or raw input authority.
