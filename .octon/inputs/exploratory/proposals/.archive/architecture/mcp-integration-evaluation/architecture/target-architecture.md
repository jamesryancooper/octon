# Target Architecture

MCP is implemented as a lab-evaluated connector/protocol input boundary.

The target state adds:

- a lab evaluation record for MCP integration;
- a non-live connector admission boundary record for MCP integration
  evaluation;
- retained lab proof with positive scenario evidence and negative controls;
- a shared adapter evaluation boundary contract;
- a validator proving MCP cannot become authority, support admission,
  permission, policy, or retained evidence.

MCP availability, descriptors, tool listings, prompts, resources, servers, and
outputs remain non-authoritative.
