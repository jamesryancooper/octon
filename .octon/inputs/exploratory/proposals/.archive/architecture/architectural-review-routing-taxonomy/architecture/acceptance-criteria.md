# Acceptance Criteria

- The routing table covers every review mode requested by the parent program.
- Routing is deterministic and validator-backed.
- The taxonomy distinguishes reviews, audits, packets, evaluators, lifecycle
  gates, and constitutional challenges.
- Architecture Revision Packet is not promoted into native authority.
- Constitutional challenge escalation is explicit.
- Routing receipts include selected route, rejected candidate routes, evidence
  refs, validator refs, and non-authority classification.
