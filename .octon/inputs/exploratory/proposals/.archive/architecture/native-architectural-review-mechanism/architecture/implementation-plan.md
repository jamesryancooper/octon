# Implementation Plan

## Phase 0: Proposal Program Creation

Create this parent program and ten sibling child packets. Validate packet
structure, proposal standards, architecture proposal requirements, generated
registry, and compact artifact projections.

## Phase 1: Native Doctrine, Naming, Routing, And Schemas

Implement the first three child packets:

1. `architectural-review-native-doctrine-and-naming`
2. `architectural-review-routing-taxonomy`
3. `architectural-review-schemas-and-receipts`

This phase establishes the canonical vocabulary and strict support receipt
schemas before any lifecycle gate wiring.

## Phase 2: Workflows, Thin Invocation, And Lifecycle Gates

Implement:

1. `architectural-review-native-workflows`
2. `architectural-review-native-skills-commands`
3. `architectural-review-proposal-lifecycle-integration`

Lifecycle gate wiring starts only after strict support receipt schemas and
validators are available. The mandatory gate is Pre-Integration Architecture
Review for architecture proposal acceptance and implementation authorization.

## Phase 3: Closeout Boundaries And Mechanism Index

Implement:

1. `architectural-review-post-integration-boundaries`
2. `architectural-review-governed-mechanism-integration`

This phase preserves implementation conformance and drift/churn as hard
closeout gates while positioning post-integration architecture review and
lifecycle postmortem output as retained evidence unless explicitly selected by
later policy.

## Phase 4: Extension Split, Compatibility Cleanup, Validation, And Rollout

Implement:

1. `architectural-review-extension-split-cleanup`
2. `architectural-review-validation-publication-rollout`

This phase updates extension prompts and tests, retires confusing permanent
aliases, refreshes generated projections, adds fixtures and negative controls,
and records rollout evidence.

## Completion Gate

The program may be closed only after every child packet reaches its own
implemented or rejected terminal disposition and implemented children retain
passing implementation-run, conformance, drift/churn, promotion, and closeout
evidence.
