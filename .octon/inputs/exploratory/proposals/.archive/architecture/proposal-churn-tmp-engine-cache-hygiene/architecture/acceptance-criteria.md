# Acceptance Criteria

- `.tmp` output remains ignored, local, rebuildable, and bounded.
- Every scratch/cache root has a declared maximum file count, maximum byte count, TTL, and cleanup trigger, or an explicit owner-routed exception.
- Cleanup defaults to dry-run and refuses retained evidence/control/generated-effective/host projection surfaces.
- File and byte budgets are measurable after representative lifecycle runs.
- Rebuildability proof exists for pruned scratch.
- Cleaned ephemeral residue is not claimed as fully reconstructable.
