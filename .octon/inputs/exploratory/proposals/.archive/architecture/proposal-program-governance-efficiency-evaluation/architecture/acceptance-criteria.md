# Acceptance Criteria

The program is acceptable for review when:

- every child packet is a sibling proposal packet, not nested under the parent;
- every child has a distinct implementation scope and promotion target set;
- the parent registry, human index, sequence, child contract, and closeout plan agree;
- the proposed evaluator remains read-only and advisory by default;
- no parent artifact satisfies child-owned receipts, validation verdicts, archive metadata, cleanup dispositions, or terminal outcomes;
- the validation plan includes negative controls for advisory-only behavior.
