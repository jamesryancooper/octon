# Acceptance Criteria

- `validate-run-program-clean-delivery.sh` invokes or requires evidence-disclosure validation for terminal claims.
- Missing delivery receipt or evidence index fails.
- Open blockers fail.
- Remote/local mismatch or unsynced local main fails when publication or landing is claimed.
- Dirty worktree status fails terminal `git_clean_terminal` proof.
- Negative fixtures cover all postmortem false-terminal states.
