# Acceptance Criteria

This child packet is implementation-ready when:

1. The architecture index home is scoped under authored architecture docs.
2. The index declares `governed cross-surface mechanisms` as the preferred
   architecture/governance term.
3. The index declares product docs use `product features`.
4. Runtime/operator docs remain concrete lifecycles, workflows, routes, state
   machines, receipts, commands, and skills.
5. Every mechanism entry must name required surface classes.
6. Every mechanism entry must name ownership and delegation boundaries.
7. Every mechanism entry must name explicit non-authority boundaries.
8. The index says mechanism index not runtime authority.
9. The index preserves generated, raw/input, host, chat, model memory, tool
   availability, and product catalog non-authority rules.
