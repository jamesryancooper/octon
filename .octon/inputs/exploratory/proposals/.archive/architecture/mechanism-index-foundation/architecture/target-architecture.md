as the durable architecture/governance home for governed cross-surface
mechanisms.

The foundation should include:

- `README.md` as the mechanism index entry point.
- A layered terminology guide preferring `governed cross-surface mechanisms`
  for architecture/governance docs.
- A glossary for feature, mechanism, lifecycle, state machine, workflow, route,
  contract, capability, subsystem, control plane, and evidence plane.
- An authority-class guide aligned to the topology registry.
- A mechanism entry template requiring surface maps, authority classes,
  ownership/delegation boundaries, non-authority boundaries, validators, and
  source dependencies.
- Boundary notes for lifecycle versus workflow versus route versus state
  machine, repo hygiene delegation, Mission Runner candidate preparation, and
  lifecycle interaction receipt non-authorization.

The index must explicitly state that it is mechanism index not runtime
authority.
