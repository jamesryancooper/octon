# Acceptance Criteria

- Recoverable blocker retries enter compact blocker-remediation mode and emit
  one compact receipt plus bounded logs when blocker fingerprints repeat.
- Artifact budget breaches use repeated fingerprint, file count, and byte size
  signals and continue with throttled evidence production unless required
  evidence would be lost.
- Recoverable hygiene blockers run target-owned preserve/exclude routes,
  emit fresh return evidence, rerun the blocked gate, and continue downstream
  automatically when the gate passes.
- Stale local branches with no unique commits are retired automatically after
  proof of no upstream-only state, no open PR, no protected naming/status, and
  safe dirty-worktree disposition.
- Run-health projections are diagnostic by default and do not dirty tracked
  generated files during validators unless an owning publisher explicitly
  promotes them with a receipt.
- Hosted no-PR landing proceeds non-interactively only when a current receipt
  proves source and target refs, exact SHA, checks or approved empty-check-set
  rationale, no-PR status, host-control preservation, rollback handle, and final
  sync plan.
- Final reports identify every retained branch, retained worktree, retained
  evidence root, generated/local-private residue class, deleted residue class,
  and manual-review item without overclaiming branch cleanup or terminal
  hygiene.
- Human review remains required for foreign or ambiguous residue that cannot be
  safely preserved or excluded, destructive cleanup without route authority,
  protected refs, external credentials, provider policy denial, stale receipts,
  or conflicting operator instructions.
