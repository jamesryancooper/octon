# Packet Sequence

1. `run-program-clean-delivery-compact-blocker-remediation`
   - Establish the compact retry mode and artifact-budget contract before other
     autonomous recovery paths depend on bounded evidence.
2. `run-program-clean-delivery-autonomous-hygiene-continuation`
   - Convert recoverable worktree, ownership, and stale-fingerprint blockers
     into route-owned preserve/exclude continuation.
3. `run-program-clean-delivery-stale-branch-retirement`
   - Add governed local stale-branch retirement, including dirty worktree
     unanchoring, branch role labels, and no-unique-commit proof.
4. `run-program-clean-delivery-run-health-localization`
   - Move diagnostic run-health churn out of tracked generated state unless a
     publisher explicitly promotes it.
5. `run-program-clean-delivery-no-dispatch-deduplication`
   - Prevent max-step and no-dispatch resumptions from producing duplicate
     compact artifacts when no route action occurs.
6. `run-program-clean-delivery-retained-state-reporting`
   - Make final cleanup and closeout reports explicit about delivered,
     retained, local-private, deleted, and manual-review state.
7. `run-program-clean-delivery-authorized-hosted-landing`
   - Consume hosted no-PR landing receipts non-interactively only after current
     validation proves Octon authorization, host/provider controls, rollback,
     final sync, and execution-environment approval-lane coverage.

Each child must complete its own review, implementation, verification,
closeout, and archive gates. The parent may only cite child evidence by path and
digest after child routes produce it.
