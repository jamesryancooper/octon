# Target Architecture

External workflow engines are implemented as lab-evaluated, replaceable adapter
or executor candidates.

The target state adds:

- a lab evaluation record for external workflow engine adapter behavior;
- a non-live connector admission boundary record for stage-only evaluation;
- retained lab proof with positive scenario evidence and negative controls;
- a shared adapter evaluation boundary contract;
- a validator proving external engine state cannot become workflow, run,
  authorization, support, evidence, or closeout truth.
