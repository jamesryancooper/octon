# governance-efficiency-evaluate

Advisory proposal-lifecycle extension command for governance efficiency
analysis.

Delegates to the core runtime command `/governance-efficiency-evaluate` and the
validator `.octon/framework/assurance/runtime/_ops/scripts/validate-governance-efficiency-report.sh`.

This extension command is optional. It does not create a lifecycle gate, child
receipt, closeout route, archive route, cleanup route, branch landing route, or
terminal proof rule.
