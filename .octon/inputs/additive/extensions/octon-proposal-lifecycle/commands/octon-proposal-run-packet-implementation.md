# Octon Proposal Lifecycle: Run Packet Implementation

Run the `run-packet-implementation` bundle for one proposal packet by executing
`support/executable-implementation-prompt.md` against durable repository
surfaces, then update the post-implementation conformance and drift/churn
receipts before routing to verification or correction.

Boundary: this leaf must satisfy the proposal implementation gates before
effectful execution. It does not own lifecycle planning, phase-loop state,
Change closeout, hosted landing, branch cleanup, or final Change lifecycle
outcome reporting.
