Run only when an operator asks for advisory efficiency analysis. Use the core
runtime scripts and preserve the report's advisory-only classification.

The output cannot authorize review, validation, closeout, cleanup, archive,
terminal proof, policy mutation, lifecycle transition, or child receipt
substitution.
