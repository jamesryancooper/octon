# Subsystem Targeted Integration: Build Subsystem Packet

Turn the verified subsystem-scoped concepts into one architecture proposal
packet.

## Shared Contracts

- apply `../../shared/managed-artifact-contract.md`
- apply `../../shared/architecture-packet-contract.md`
- apply `../../shared/architecture-review-method.md` when the packet contains
  architecture recommendations

## Output

Produce a subsystem-scoped architecture packet with explicit cross-subsystem
dependency notes when required. For architecture recommendations, include the
review charter, system job, current reality maps, current architecture
steelman, constraint and complexity ledgers, bottleneck analysis, failure-mode
analysis, quality/hardening criteria, rollback posture, and Octon-fit gates.
