# Incoming Intake: Octon Architecture Review Prompt Library

This directory is a non-authoritative incoming additive intake packet retained
after stop-after-classification evidence for a later pilot review.

Raw and intake-maintenance material lives under `payload/`. The top-level
`intake.yml` records intake-time envelope facts only; it does not authorize
installation, normalization, activation, publication, proposal creation, or
runtime use.

The retained prompt text has been normalized in place for the deferred pilot:
legacy source-model wording is replaced with `Octon Architect`, and the prompt
library is model-agnostic — it pins no specific execution model.

The conversation thread used to create the prompt library is retained at
`payload/source/conversation-thread.md`.
