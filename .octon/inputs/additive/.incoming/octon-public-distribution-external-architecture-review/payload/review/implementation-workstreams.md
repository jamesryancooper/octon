# Implementation Workstreams

## Phase 1: Foundations

- `public-distribution-legacy-exposure-readiness`: redacted history exposure,
  credential response, and repository-transition preconditions.
- `public-distribution-repository-role-contracts`: four-surface topology,
  ownership, Git posture, and update boundaries.

## Phase 2: Parallel Foundations

- `public-distribution-portable-base-clearance`: component closure, license,
  provenance, sensitivity, and publication clearance.
- `public-distribution-downstream-core-delivery`: lock, resolver, cache,
  neutral initialization, update, recovery, and rollback.
- `public-distribution-local-storage-evidence`: truthful local-private
  evidence, retention, backup, compact receipts, and Git-posture policy.

## Phase 3: Materialization And Workspace Root

- `public-distribution-portable-dropin-export`: exact-commit deterministic
  export, manifests, denylist, and parity.
- `public-distribution-self-hosting-workspace-migration`: root Git policy,
  workspace workflows, ownership metadata, and host projections.

## Phase 4: Public Controls And Octon Storage

- `public-distribution-public-repository-controls`: public-only scaffold,
  desired-state plan, secure CI, candidate build, and manual publication.
- `public-distribution-self-hosting-octon-storage-migration`: classified
  forward-only untracking of state and generated output.

## Phase 5: Integrated Readiness

- `public-distribution-pilot-release-readiness`: public-style, private, and
  offline pilots; Tier 1 matrix; fault injection; candidate and release
  verification.

## External Barrier

Live repository creation, rename, visibility, rules, first import, and release
remain outside program orchestration. They require a separately approved exact
operations plan.
