## Precise Specialist Triggers

### Licensing Or Rights

Trigger: an exported component has ambiguous external origin, incompatible
license obligations, uncertain generated-template treatment, or disputed
publication permission.

Why architecture cannot resolve it: repository structure cannot prove rights.

Release impact: block only the affected component or closure until resolved.

### Trademark

Trigger: the basic search identifies a plausible conflicting software or
technology mark, or impersonation or commercial use occurs.

Why architecture cannot resolve it: likelihood of confusion is not a technical
property.

Release impact: blocks name acceptance when the conflict is plausible.

### Security

Trigger: confirmed exposed credentials, material private data, malicious
history content, account compromise, or a scanner finding whose exploitability
is unclear.

Why architecture cannot resolve it: incident scope and response depend on facts
outside repository structure.

Release impact: revoke credentials immediately; block transition until
disposition is recorded.

### Release Or Platform Operations

Trigger: GitHub does not support an assumed ruleset, attestation, immutable
release, or credential workflow for the personal-account configuration.

Why architecture cannot resolve it: platform capability is time-dependent.

Release impact: select the simplest equivalent control or revise the affected
decision explicitly.
