# Superseded And Deferred Decisions

## Superseded

- Publish or rename the full workspace as public Octon.
- Use workspace Git history, clone, mirror, subtree split, or ancestry
  projection as distribution history.
- Use `bootstrap_core`, `repo_snapshot`, `pack_bundle`, or
  `full_fidelity` as the base public boundary.
- Export all `framework/**` solely because it is portable by role.
- Ship additive packs in the base release.
- Commit downstream framework snapshots by default.
- Treat all `inputs/**` as one Git or sensitivity class.
- Treat non-authority, generation, private hosting, or Git ignore as
  publication clearance.
- Commit raw evidence, state, generated effective output, logs, caches, and
  host projections routinely.
- Use a cross-repository PAT, automatic merge publication, or a ceremonial
  second-person requirement.
- Keep root workspace migration and `.octon/**` storage migration in one
  mixed-target packet.

## Deferred And Activation Triggers

| Control | Trigger |
| --- | --- |
| GitHub organization | Multiple maintainers or organizational custody |
| Public code contributions | Reviewed intake, moderation, review, and governance model |
| GitHub App | Repeated cross-repository automation justifies credential isolation |
| Independent signing key | Regulated, air-gapped, or independent-registry trust requirement |
| Hosted immutable evidence | Collaboration, regulation, or recovery exceeds local encrypted backup |
| Scheduled evidence compaction | Evidence volume creates measured burden |
| Automated evidence deletion | Mature classification and explicit deletion policy |
| Tier 2 release gating | Reliable lifecycle testing on preview targets |
| Committed vendoring | Verified offline or policy-constrained adopter |
| Internal artifact mirror | Repeated constrained-network or organizational need |
| Automatic instance migration | A real versioned instance schema transition |
| Formal trademark registration | Plausible conflict, impersonation, or commercial adoption |

External architect task: identify any deferred control whose risk-reduction value
already exceeds its solo-maintainer cost.
