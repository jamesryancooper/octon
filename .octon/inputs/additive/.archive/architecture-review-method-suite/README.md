# Incoming Intake: Architecture Review Method Suite

This directory is a non-authoritative incoming additive intake unit for an
Octon architect handoff. It captures the conversation-derived direction for
creating a proposal program around an Architecture Review Method Suite.

The top-level `intake.yml` records intake-time facts only. It does not
authorize proposal creation, implementation, methodology mutation, route
publication, generated projection refresh, validator changes, or runtime use.

Raw handoff material lives under `payload/`.
