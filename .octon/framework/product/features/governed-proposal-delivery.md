# Governed Proposal Delivery

## Proposal Program Delivery

Program delivery coordinates target-owned child implementation or archive-
readiness evidence in child-before-parent order. Current admission is limited
to `implemented` and `archive-ready` with `route=stage-only`.

Effectful/default requests fail with
`RP00_CONTAINMENT_PUBLICATION_DISABLED`. Exact work remains preserved and the
feature performs no direct-main, hosted branch-no-PR, landing, sync, cleanup,
Git/GitHub, provider, archive relocation, or branch-deletion effect.
