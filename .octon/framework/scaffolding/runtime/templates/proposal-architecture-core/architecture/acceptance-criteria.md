## External Tool Integrity

- Every external tool remains an unmodified supported release.
- Every required behavior is implemented and validated in Octon-owned code.
- Tests prove the declared supported interface and fail-closed behavior.
- No acceptance condition depends on an upstream modification or private
  external-tool derivative.
