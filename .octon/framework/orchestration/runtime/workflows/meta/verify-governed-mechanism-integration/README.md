# Verify Governed Mechanism Integration

_Generated README from canonical workflow `verify-governed-mechanism-integration`._

## Usage

```text
/verify-governed-mechanism-integration
```

## Purpose

Verify that a governed mechanism implementation has complete cross-surface profile evidence, validated receipts, publication freshness, and authority-boundary protection before proposal closeout.

## Target

This README summarizes the canonical workflow unit at `.octon/framework/orchestration/runtime/workflows/meta/verify-governed-mechanism-integration`.

## Prerequisites

- Required workflow inputs are available.
- Canonical workflow contract exists at `.octon/framework/orchestration/runtime/workflows/meta/verify-governed-mechanism-integration/workflow.yml`.

## Parameters

- `proposal_path` (folder, required=true): Root proposal directory whose governed mechanism integration is being verified
- `mechanism_id` (text, required=true): Governed cross-surface mechanism identifier from the mechanism index
- `mechanism_profile_ref` (file, required=true): Repo-relative governed mechanism integration profile to validate
- `mode` (text, required=false), default=`implementation`: Verification mode: implementation, closeout, or archive
- `run_id` (text, required=false): Optional retained evidence run id

## Failure Conditions

- Required inputs are missing or invalid.
- The canonical workflow contract or stage assets are missing.
- Verification criteria are not satisfied.

## Outputs

- `governed_mechanism_integration_receipt` -> `{{proposal_path}}/support/governed-mechanism-integration-evaluation.yml`: Packet-local evidence receipt for governed mechanism integration verification
- `governed_mechanism_integration_bundle` -> `/.octon/state/evidence/runs/workflows/{{run_id}}/governed-mechanism-integration/{{mechanism_id}}/`: Retained workflow evidence bundle containing profile, receipt, validation logs, and evidence inventory

## Verification Gate

- [ ] validate-governed-mechanism-integration-profile.sh passes for `mechanism_profile_ref`
- [ ] validate-governed-mechanism-integration-receipt.sh passes for `support/governed-mechanism-integration-evaluation.yml`
- [ ] validate-proposal-implementation-conformance.sh and validate-proposal-post-implementation-drift.sh pass before an implementation verdict is accepted
- [ ] generated publication refs are regenerated by canonical publishers or explicitly validated fresh, never edited by hand

- [ ] closeout and archive modes also pass validate-proposal-lifecycle-terminal-freshness.sh
