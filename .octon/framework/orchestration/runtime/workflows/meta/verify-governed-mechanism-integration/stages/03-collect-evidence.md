# Collect Evidence

Collect evidence refs for:

- implementation conformance review,
- post-implementation drift/churn review,
- generated publication freshness checks,
- terminal freshness checks when `mode` requires them,
- current-state mechanism architecture review evidence,
- lifecycle postmortem evidence when available,
- validator command outputs.

Current-state architecture review and lifecycle postmortem refs are evidence-only. They cannot replace the conformance, drift/churn, generated publication freshness, or terminal freshness gates.
