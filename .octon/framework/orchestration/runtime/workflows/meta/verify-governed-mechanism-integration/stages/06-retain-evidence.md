# Retain Evidence

Retain a workflow evidence bundle at:

```text
/.octon/state/evidence/runs/workflows/{{run_id}}/governed-mechanism-integration/{{mechanism_id}}/
```

Include the validated profile, emitted receipt, command transcript summary, evidence inventory, and any explicit non-authority classifications used to reach the verdict.

Do not copy generated outputs as authority. If copied for auditability, mark them as generated, derived, and non-authoritative.
