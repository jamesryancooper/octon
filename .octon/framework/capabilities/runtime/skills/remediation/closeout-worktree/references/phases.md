# Phases

1. Bind exact refs, worktrees, status, and rollback handles.
2. Classify all residue read-only.
3. Partition candidates with exact ownership and boundaries.
4. Preserve each candidate without delegation.
5. Re-inventory and prove no material action occurred.
6. Emit the preservation report and later-owner recommendation.

No phase stages, commits, pushes, lands, syncs, cleans, deletes, prunes,
archives, publishes, removes worktrees, mutates refs, or invokes a downstream
effect route.
