# Audit Surface Architecture

Invoke the skill at:

- `/.octon/framework/capabilities/runtime/skills/audit/audit-surface-architecture/`

`audit-surface-architecture` is an operator invocation alias for the canonical Architectural Review Mechanism mode `surface-architecture-audit`.
The skill is read-only and emits retained audit evidence; this command does not
create a lifecycle gate or proposal acceptance authority.
