# Git Pack

Governed pack for route-aware Git preservation and bounded mutation primitives.

During SI-00, the pack supports branch-only checkpoints or commits, preserved
handoff, and PR-backed coordination after the canonical default work unit
policy selects a Change route. Direct-main is not admitted. Branch-no-PR
landing and all branch cleanup effects deny before mutation with the stable
RP-00 containment reasons. Branch and PR helpers remain implementation tools;
they are not the default work unit or authority to publish or clean up.
